# Project Overview

ShopVerse is a full-stack MERN E-Commerce web application developed using:

- React.js
- Node.js
- Express.js
- MongoDB

The application allows users to:
- Sign up and log in
- Browse products
- Add products to cart
- Increase/decrease quantity
- Checkout orders
- Manage user sessions

The project also includes:
- Admin/User role-based access
- Product management APIs
- Order management APIs
- Responsive UI design

# API Endpoints

## Authentication APIs
- POST /auth/signup
- POST /auth/login

## Product APIs
- GET /products
- POST /products
- PUT /products/:id
- DELETE /products/:id

## Order APIs
- POST /orders
- GET /orders
